# LuxeBot: AI-Powered Virtual Concierge 🏨

**LuxeBot** is a high-end, minimalist FAQ chatbot tailored for luxury hotels and restaurants, providing instant, intelligent responses to guest inquiries.

---

## 📖 Description
LuxeBot streamlines the guest experience by automating front-desk inquiries. Built using **Natural Language Processing (NLP)**, it analyzes guest intent via **TF-IDF Vectorization** and **Cosine Similarity**. Instead of simple keyword matching, LuxeBot understands the context of a query, ensuring guests get the right information about check-ins, dining, and hotel services instantly.

---

## ✨ Features
* **Semantic Intelligence:** Understands guest intent using Scikit-Learn’s TF-IDF.
* **Premium UI:** A distraction-free, "Midnight Teal & Gold" interface built with Gradio.
* **Smart Suggestions:** Provides relevant "You might also want to know" hints.
* **Automated Preprocessing:** Intelligent text cleaning and stopword removal via NLTK.
* **Hospitality Focused:** Pre-loaded with professional hotel and restaurant knowledge.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** Gradio (Frontend), Scikit-Learn (ML Logic), NLTK (Text Processing), Pandas (Data Management).
* **Algorithms:** TF-IDF Vectorization, Cosine Similarity.
